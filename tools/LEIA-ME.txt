PRÉVIA COM FOTO NO WHATSAPP (páginas de produto)

O que faz: a cada 30 minutos o GitHub gera, sozinho, uma página por produto com estoque
(catalogo/p/<id>.html) com foto, nome e preço. Quando o cliente toca em "Chamar no WhatsApp",
o link dessa página vai na mensagem e o WhatsApp mostra um cartão com a foto do produto.

COMO ATIVAR (uma vez só)
1) No repositório (MultMixnp) envie estas duas coisas, mantendo as pastas:
     .github/workflows/paginas-produto.yml
     tools/gerar-paginas-produto.mjs
   Dica: se o upload não aceitar a pasta .github, no GitHub use Add file > Create new file,
   digite o nome .github/workflows/paginas-produto.yml e cole o conteúdo do arquivo.
2) Publique também o catálogo novo (catalogo 1.6.0).
3) No GitHub: Settings > Actions > General > Workflow permissions > marque
   "Read and write permissions" > Save.
4) Aba Actions > "Páginas de produto (prévia do WhatsApp)" > Run workflow (roda na hora).
   Deve terminar verde e criar a pasta catalogo/p/ com um arquivo por produto.
5) Teste: abra https://SEU-USUARIO.github.io/MultMixnp/catalogo/p/ID-DO-PRODUTO.html (vai abrir o produto)
   e mande o link para você mesmo no WhatsApp: deve aparecer o cartão com a foto.

OBSERVAÇÕES
- Produto novo ou alterado leva até 30 min para ter a prévia. Enquanto isso, o botão manda o link
  simples da foto (sem cartão). Para adiantar: Actions > Run workflow.
- Produto sem estoque ou inativo tem a página apagada sozinha.
- Só usa dados públicos do catálogo. Não usa senha nem chave secreta.
- O WhatsApp guarda a prévia de um link por um tempo; se trocar a foto, a prévia antiga pode demorar a sumir.
- Custo: nenhum (GitHub Actions é grátis para este uso). Se o repositório for privado, conta nos minutos grátis do plano.
